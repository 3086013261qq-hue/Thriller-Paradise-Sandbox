### 时间线开关

必须手动**先关闭目前半卷，再开启下一半卷**。例如：
第一卷（上）→ 第一卷（下）→ 第二卷（上）→ 第二卷（下）；绝不能同时开两段或一次开启完整14卷。

### 触发安全

### 浮球与数据

本卡**没有MVU**。输出规则仅令AI给出`<story_scene>`和`<status>`原生文本；未来酒馆助手脚本读取最新消息的状态渲染为可点击悬浮球。请注意：这是模型生成的文字状态，精确数值需要剧情或已确认状态支持，不等于自动可信的MVU数值存储；缺失数据不得猜测。设计A/B须用户选定后才写DESIGN及脚本。
