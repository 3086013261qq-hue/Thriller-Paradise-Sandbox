## 正式正文要求
1. 严格复用**咩咩制卡包·全栈原生 <world_timeline>**；正式写作前核对母版原生字段及标签，不自创新schema，不修改咩咩预设。目录Markdown并非正式时间线正文。
2. 原著**真实剧情推进**为分卷依据，非游戏赛季或原著自带卷标；时间线每一条保留原题／章节锚点，按卷内 A/B/C 与连续事件 A1/A2 等规则排列。
3. **现实层**是2055年起、延续至2056年的时间轴；**游戏体验层**受登录模式、下线、睡眠倍率影响；**剧本内层**可另有历史/未来日期、时间回溯、循环或架空纪年。三者分别标记，不得将剧本日期写成现实日期。
4. 实际确定的日期使用 YYYY年MM月DD日；跨现实日的连续事件必须核对原著再推进日期。未证实的日、时、跨度，先列为“日期待核”，不得编造 YYYY年MM月DD日 或假称原著写明。
5. 先铺现实时间证据表（明确日期→相对天数→同期其他人物事件），再将剧本内部事件挂接到对应现实登录；对原著倒叙、插叙和揭露真相采用“事件实际发生时点”与“人物知晓时点”双标识。
6. 后期隐藏真相、升级装备、能力/身份/阵营变更按对应剧情阶段解锁；不得在前期让NPC提前知晓，亦不得把一次性剧本资产写成常驻私有装备。
7. 每卷正文由该卷原始章节定位与正文事实复核后另行制作并提交QA；目录通过不等于任何卷自动完成；目前第一卷经QA020、第二卷经QA021、第三卷经QA022、第四卷经QA023、第五卷经QA024、第六卷经QA025、第七卷经QA026、第八卷经QA027审核，第九至十四卷未制作，亦不等于 Android/SillyTavern 实机通过。
