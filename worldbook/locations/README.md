## 一、减法准则

- **地点是反复可用的舞台，不是剧情章节摘要。** 一次性关卡、短篇剧本、无专名的小场景，一律交给已冻结的14卷时间线；不为了覆盖1518章强行给每个地点建独立卡。
- **蓝灯负责抽象空间结构、绿灯负责游戏系统规则、地点负责能落脚的场景。** “天堂/地狱/主宇宙/时间之河/数据链路层”等概念不能因出场次数高就都转独立地点。
- **父地点能够提供场景的，子地点不拆。** 同一镇的寺庙、岛上的酒店和家宅、城内的普通教室、医院里的某间病房归入母地点说明；仅将来确有独立而反复使用的必要时重新提议。
- **同一地点出现多个阶段只建一条。** 《咀魔岛》重返、努卡市再出现、同名译法，采取地点身份消歧与时序状态，不复制条目。
- **正式地点保留原名。** 原著没有固定专名但确实需要定位的候选，须在目录上明确为描述性目录名，不能伪装成作者官方地名。
- **剧情信息差保护。** 2055～2056的现实时间、剧本内历史/主观时长、高位真相揭露、2056年04月21日REWRITE前后，依冻结时间线呈现，不把后期状态灌入前期。
- **不设硬性配额。** 26个只是缩减后的审查起点，后续原文发现遗漏核心稳定舞台，可附QA新增；失去独立必要性的也继续剔除。

特别说明：

1. `荷月镇`条可包含`六和寺`空间信息，但不声称寺庙处于镇子内部；是篇章父地点合并，不是篡改地理。
2. `葬心山庄`条可介绍`断魂峡`及相关行经路线，但峡谷不是山庄附属建筑，不得造假。
3. `登陆空间`与`公共空间`不是同一个房间；删去后者独立卡仅代表由系统绿灯和相邻场景处理，不等于声称物理合一。
4. `主宇宙`作为跨世界结构依然由蓝灯完整保留；独立领域`混沌焦土`、`死灵王国`保留地点候选，不是删掉宇宙设定。
5. `宇超联`仍作为组织与系列剧本贯穿原著，只是不默认给整个组织和它的每座设施分别建地点卡。
6. `高谭市`不同副本版本、`咀魔岛`早晚状态、`蔻奇柯缇岛`内部酒店与宅邸，遵守时间线/空间层级及人物当时知情范围，不把不同版本或历史混同。

## 五、生产计划

1. 以P0实际空间为第一批：核对S市、封不觉住处、梦公司总部、登陆空间，先产一条正式样本并复核格式。
2. 再审核并制作里世界、混沌焦土、死灵王国3条高位核心地点，不提前公布剧情真相。
3. P1按照原著先后按小批次制作，每批须原文校验、独立性复审、原生格式检查、剧透防护和GitHub提交。
4. 全部完成后才总审地点条目与触发词重复，继而全卡联合QA及装卡。

## 六、原生格式与装配边界

正式正文仅使用已核定的全栈`<地点:正式名称>\n介绍:...\n</地点:正式名称>`；不增加自创schema。来源章节、候选名单、去重原因写于QA，运行时通过预设既有`当前位置:`与世界书触发规则，不修改咩咩预设。
