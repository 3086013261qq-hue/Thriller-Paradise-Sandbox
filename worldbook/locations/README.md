## 一、选择与分层

- **P0 核心**：现实中可反复回访的地点，以及剧本、主宇宙、里世界所需的高位稳定空间。涉及机构/维度词的条目保留“候选复核”状态，不能自动转正式卡。
- **P1 章回舞台**：故事确实在其中展开、可独立支持扮演的城市、岛、学校、关卡或固定设施；按“原著有专名”和“仅能给描述性目录名”两池分开。
- **P2 子地点**：在父地点内部有独立场景身份、特殊规则或稳定的反复触发需要，才拆成自己的地点卡；临时房间、街巷、普通商店默认并入父地点。
- 一个地点跨卷回访**只建一份正文**；同地不同阶段、同名不同剧本版本与不同知情范围在正文及时间线中分层表达。
- **目录不等于全部制作承诺**：P0候选及P1描述性条目均要过逐条“是否真正有独立场景”二审；无法过审的留在QA剔除池，不为凑数而建卡。
- 触发优先采用咩咩全栈状态栏的`当前位置:`，最终装配才设置关键词、order与after_char，不在目录内模拟预设状态机。

## 六、去重与不收录锁

1. **努卡市**：前期《大蒜无双》／后期关联章节中同名城市，仅保留P1-A一条，版本差异按原著核。
2. **咀魔岛**：第五卷初访／第十二卷重返合并；“正岛、逆岛”先当同岛机制，非直接独立两张卡。
3. **高谭／哥谭**：翻译与多剧本版本先并主显示名，只有原著实证“不同宇宙同名地点”时才允许在正文叙明版本，而非擅自把两个剧情混成同一日。
4. **雪松郡医院／《被诅咒的医院》**：场所名与剧本标题互指，医院只保留一条；不要把早期双人训练病院当成同一医院。
5. **《黑白鬼域》与平田世界**：属于同一剧本系统的候选舞台，避免以标题与叙事人名拆两套地图。
6. **苍灵镇／铃中境／破庙**：父镇、不同空间层和普通子地点分开审核，破庙非自动独立。
7. **荷月镇／六和寺**：父镇和山寺分层，两个都有实际场景身份。
8. **蔻奇柯缇岛／阿尔弗雷德酒店／赫伯特宅邸**：岛屿父地点和两处独立内部舞台区分。
9. **现实万圣节嘉年华**不是《惊悚乐园》游戏副本；雅歌号是现实游轮，不是虚拟道具。
10. **九科、赌皇斋、梦公司、宇超联**：组织名不自动等于一栋可定位建筑；只有“梦公司总部”“宇超联总部”等原文明确实体才纳入地点候选。
11. **地狱前线、秩序、尸刀、惊吓盒子、拍卖行（UI）、角色技能名称、任务名称、四柱神名称**不作为地点本体；若有真实场馆或总部需另有证据。
12. 《大蒜无双》《诡影迷城》《进击的主角》《被诅咒的医院》《圣诞寻宝》《至黑之夜》《REWRITE》等**剧本／事件标题并非地理专名**；仅有可定位、具规则场景才可为其建立描述性地点候选。
13. 普通战斗街道、一次性舱室、校园单个教室、商场柜台、酒店单个客房、临时NPC营地、无专名的星际路线不独立建条。
