# 《惊悚乐园》｜咩咩制卡包·全栈原生地点格式

本文件为**格式说明，不是正式地点正文**。参照用户已使用且完成格式核对的咩咩全栈`lore-place`运行条目规范；只适配本书现实／剧本／里世界空间，不修改预设。

正式地点正文仅有：

```text
<地点:正式名称>
介绍:关于空间、环境、出入方式、固定功能、居民、规则及原著时间状态的客观描述；按真实剧情先后说明状态变化，不能把后期结果提前覆盖早期。
</地点:正式名称>
```

**禁令**：
1. 不增造`<location>`、`<场景状态锁>`、`<剧本时间>`、`<空间类型>`等非原生运行标签；目录/QA负责工程元数据。
2. 只有可独立反复使用、需要独立`当前位置:`触发的空间才单独做条；同地变化合并在一份`介绍:`。
3. 不把现实S市/住房/梦公司总部、惊悚乐园虚拟副本、主宇宙、里世界、重写后现实混成一张现实地图。
4. 地点介绍只描述客观空间与可见社会结构，不指定“玩家必须经历某结果”，不复制完整时间线与人物能力。
5. 每个叙事阶段的秘密信息按当时人物已知范围表达；时间锚源于已封版时间线，不额外创造现实日期、装备奖励或胜负。
6. 缺原著地名者，候选目录明确注记`【描述性目录名，原著无专名】`；正式成条前再审是否有必要独立存在。
7. 最终装配时地点与咩咩全栈成熟`lore-place`区兼容（触发型、after_char、`当前位置:`），装配参数只在未来manifest/assembly阶段确定；现在不触碰已有预设和封版条目。
