## 制卡范围

## 双时间兼容规则（待装卡实测）
- 时间线仍采用原生单块 <world_timeline>，独立事件用 A/B/C，连续阶段用 A1/A2；保留原事件标题与格式。
- 事件括号中的主时间锚点始终代表现实主线；可在有需要的事件内附加 <现实时间> 与 <剧本时间> 说明。
- <现实时间>：现实世界主线的时序与进度依据；<剧本时间>：当前剧本内部的时间，不作为现实主线推进依据。
- 只有在剧本内事件需要对照时附加 <剧本时间>；非剧本事件不强制双标签。
- 进入或退出剧本时不得把剧本经历的年月日直接加到现实时间；现实实际流逝以原著明确说明或已确认的故事事实为准。
- 原著未提供的现实精确日时须标为「制卡时间锚点」或待核实，不冒充官方日期。
- 新增标签是世界书自定义解释标记，并非咩咩预设原生专用字段；在最终装卡时用实机验证模型是否稳定遵守。
- 时间线原著事件的触发、蝴蝶效应及与玩家互动继续由既有咩咩预设承担。
